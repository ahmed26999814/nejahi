## Behavior changes

- A green and gold homepage with a direct year → competition → candidate-number form, responsive year cards, visible labels, native selects, numeric Android keyboard, clear connection errors and retry.
- The existing year/competition navigation, rankings, statistics, sharing, subject details, notification registration, lessons and administration remain available.
- Search accepts Arabic/Persian digits, rejects oversized API inputs without truncating them, cancels superseded requests, and prevents reuse of another source's rank. The five `*_2026` search aliases now resolve to the published 2026 upload sources rather than the 2025 built-in sources.
- Guided Concours 2025 uses the existing server lookup RPC with all location fields, through a cache keyed by candidate and location. It no longer depends on a public Supabase key in the browser. Uploaded Concours keeps its existing centre-shard path.
- `/api/debug` requires the existing admin secret before any database request, uses constant-time comparison, does not return sample student rows, and disables storage/indexing of its responses. Admin pages and API responses are excluded from indexing. Other admin authorization contracts are retained.
- `/apk` is a real lowercase route. Scoped Node.js middleware redirects exactly `/Apk` to `/apk`, avoiding the previous case-insensitive redirect loop. Historical APK URLs retain their redirects. Optional download-counter failures cannot prevent the redirect. The download page checks file availability and offers retry when the file is unavailable.
- Excellence and supplementary 2026 SEO pages are marked published, matching the observed public catalogue. Unsupported competition/year URLs return HTTP 404. Social metadata uses the existing PNG logo.
- Publication notices share the loaded catalogue instead of polling it separately. Expired countdowns no longer assert publication based on the clock. Catalogue failures return an explicit retryable error rather than a misleading incomplete list. Headless HTTP clients are not automatically classified as obsolete mobile apps.
- Reduced-motion support, stable logo dimensions, reserved loading space, a skip link and French CMS-label handling improve accessibility and visual stability. The existing homepage verse is rendered in React before paint instead of inserted later by a DOM script. The result decision component is loaded when needed.
